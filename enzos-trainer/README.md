# MATTBEAR – Enzo’s Trainer

Browser training tool: menu reference, recall test, exact-sequence pizza assembly, and Pizza Rush (five orders in five minutes). Splash and admin convenience code: 1488. These client-side locks are not secure staff authentication.

## Restaurant-only menu audit — October 1, 2026

60 entries: 51 from Enzo’s Michigan website menu plus nine Flushing ordering specials. 21 specialty pizza builds. No Postmates, DoorDash, order.online, or Slice menu content is used in this version.

- https://enzospizzeria-mi.com/menu/
- https://enzospizzeria-mi.com/wp-content/themes/enzos-pizzeria/js/app.js?ver=1790098374 — menu arrays used by the restaurant website.
- https://enzospizzeria-mi.com/wp-content/themes/enzos-pizzeria/js/shared.js?ver=1790208340 — links Flushing to the store ordering page.
- https://enzospizzeriami.hungerrush.com/Order/Menu/3 — restaurant’s Flushing ordering menu; retrieved specials only.

The restaurant website explicitly identifies itself as a redesign preview, not the live production site. Its menu facts are restaurant-published, but complete current Flushing availability cannot be certified. Individual beverage options were not retrievable. See the store’s live menu for availability and pricing.

Corrections from prior delivery listings: Crab Rangoon drops unsupported scallions; Pickle drops unsupported herbs; Philly drops unsupported mozzarella specificity; Jalapeño Popper lists bacon before jalapeño. These match the restaurant website, not a verified kitchen construction order.

Sauce and cheese are required gameplay steps. When the public menu does not name a base layer it is labeled “confirm with kitchen.” Default sequences are base sauce, base cheese, then menu-list order; kitchen order remains unverified. Admin can edit and confirm the actual recipe. Quiz and reference use published ingredients, not inferred base layers.

Old saved unedited menus are replaced by the restaurant-source dataset. User edits remain explicitly marked as personal edits. Stats persist locally. JSON export/import preserves edits; imported custom content is not restaurant verification.

Pizza Rush requires all five saved sequences exactly, hides automatic hints, deducts ten points per wrong step, rewards clean-ticket streaks, and adds remaining seconds as a completion bonus. Leaving the pizza game ends the challenge. Practice mode retains tap, keyboard, mouse drag, and touch drag controls.

Generated food sprites are illustrative; proprietary sauces and unspecified cheese use generic representations. See assets/CREDITS.md.
